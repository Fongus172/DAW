Para usar `curl.exe` en el examen, abre PowerShell o CMD mientras tu aplicación Spring Boot esté arrancada y escribe comandos contra `localhost:8080`; para un GET puedes usar `curl.exe http://localhost:8080/api/libros`, para buscar por ID `curl.exe http://localhost:8080/api/libros/1`, para filtros `curl.exe "http://localhost:8080/api/libros?autor=Cervantes&disponible=true"`, para un POST `curl.exe -X POST http://localhost:8080/api/libros -H "Content-Type: application/json" -d "{\"titulo\":\"Don Quijote\",\"autor\":\"Cervantes\",\"ejemplares\":3,\"categoriaId\":1}"`, para un PUT `curl.exe -X PUT http://localhost:8080/api/libros/1 -H "Content-Type: application/json" -d "{\"titulo\":\"Don Quijote\",\"autor\":\"Cervantes\",\"ejemplares\":5,\"categoriaId\":1}"` y para borrar `curl.exe -X DELETE http://localhost:8080/api/libros/1`; si quieres ver también el código HTTP y las cabeceras, añade `-i`, por ejemplo `curl.exe -i http://localhost:8080/api/libros/1`; en resumen: GET consulta datos, `-X POST` crea, `-X PUT` modifica, `-X DELETE` borra, `-H "Content-Type: application/json"` indica que envías JSON y `-d "{...}"` contiene el cuerpo JSON.
