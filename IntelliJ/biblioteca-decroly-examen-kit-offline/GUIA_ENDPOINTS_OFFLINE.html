Biblioteca Decroly Examen - Guía offline de endpoints

No necesita Internet. Usa Ctrl + F para buscar: RANGO, ISBN, 409, DTO, FILTRO, BORRAR, LOCATION, CONFIGURACIÓN...

Base URL: http://localhost:8080
Plan B sin Postman: usa el navegador para GET sencillos o curl.exe para cualquier método.

Filtros de GET /api/libros

EjemploQué hace
/api/libros?autor=CervantesTexto parcial por autor; no distingue mayúsculas.
/api/libros?titulo=QuijoteTexto parcial por título.
/api/libros?anio=2024Año exacto.
/api/libros?desde=2000Año mínimo, incluido.
/api/libros?hasta=2020Año máximo, incluido.
/api/libros?desde=2000&hasta=2020Rango de años.
/api/libros?autor=Cervantes&titulo=QuijoteVarios filtros combinados.
/api/libros?limite=5Devuelve como máximo 5 resultados.
Regla: filtro válido sin resultados = 200 []. Recurso concreto inexistente = 404.

Patrones para buscar en IntelliJ

  • FILTRO TEXTO - contains + toLowerCase.
  • FILTRO POR RANGO - mínimo/máximo y 400 si el rango es inválido.
  • VARIOS FILTROS OPCIONALES - parámetros null se ignoran.
  • BUSCAR POR CAMPO ÚNICO - ISBN; sirve de modelo para DNI/email/código.
  • RESULTADO CALCULADO - DTO con conteos/totales.
  • REGLA AL BORRAR - 409 si el estado no permite borrar.
  • RESPONSEENTITY CREATED + LOCATION - POST con 201 y cabecera Location.
