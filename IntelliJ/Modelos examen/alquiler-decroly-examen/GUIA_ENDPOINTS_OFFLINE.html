Alquiler Decroly Examen

Guía local para consultar endpoints sin Internet. Usa Ctrl + F para buscar palabras como MATRICULA, DNI, DISPONIBLE, DEVOLVER, RANGO, 409, DTO o CONFIGURATIONPROPERTIES.

Base: http://localhost:8080. Los datos se guardan solo en memoria y se pierden al reiniciar.

1. Información y configuración

GET/api/alquiler/info
Lee alquiler.nombre y alquiler.max-dias mediante @ConfigurationProperties.

2. Categorías de vehículos

GET/api/categorias - Lista categorías.
GET/api/categorias/{id} - Categoría concreta. Inexistente: 404.
GET/api/categorias/{id}/vehiculos - RECURSOS RELACIONADOS.
POST/api/categorias - Crea categoría. Devuelve 201 + Location.
{
  "nombre": "Turismo",
  "descripcion": "Vehículos para uso diario"
}
PUT/api/categorias/{id} - Modifica categoría.
DELETE/api/categorias/{id} - 204 si no tiene vehículos; 409 si tiene vehículos asociados.

3. Clientes

GET/api/clientes
GET/api/clientes/{id}
GET/api/clientes/dni/{dni} - BUSCAR POR CAMPO ÚNICO. Vacío/inválido: 400. No existente: 404.
GET/api/clientes/{id}/alquileres - Alquileres relacionados con el cliente.
POST/api/clientes
{
  "dni": "12345678A",
  "nombre": "Ana Pérez",
  "email": "ana@correo.es"
}
DNI repetido: 409.
PUT/api/clientes/{id}
DELETE/api/clientes/{id} - 409 si tiene alquileres.

4. Vehículos

GET/api/vehiculos
GET/api/vehiculos?marca=Seat - FILTRO TEXTO.
GET/api/vehiculos?precioMin=30&precioMax=80 - RANGO NUMÉRICO.
GET/api/vehiculos?categoriaId=1&disponible=true&limite=5 - VARIOS FILTROS + defaultValue.
GET/api/vehiculos/disponibles - Solo vehículos libres.
GET/api/vehiculos/matricula/{matricula} - CAMPO ÚNICO.
GET/api/vehiculos/{id}
GET/api/vehiculos/{id}/alquileres - Historial del vehículo.
GET/api/vehiculos/{id}/resumen - DTO CALCULADO: total de alquileres, activos e ingresos.
POST/api/vehiculos
{
  "matricula": "1234ABC",
  "marca": "Seat",
  "modelo": "Leon",
  "precioDia": 45.5,
  "categoriaId": 1
}
El vehículo se crea automáticamente con disponible=true.
PUT/api/vehiculos/{id} - No permite cambiar manualmente disponibilidad.
DELETE/api/vehiculos/{id} - 409 si tiene alquileres.

5. Alquileres

GET/api/alquileres
GET/api/alquileres?activo=true
GET/api/alquileres?clienteId=1&vehiculoId=1
GET/api/alquileres?totalMin=100&totalMax=500&limite=5 - Rango + límite.
GET/api/alquileres/activos
GET/api/alquileres/{id}
POST/api/alquileres - CREAR + CAMBIAR ESTADO DE OTRO RECURSO.
{
  "clienteId": 1,
  "vehiculoId": 1,
  "dias": 5
}
Calcula precioTotal = precioDia * dias, crea el alquiler activo y pone el vehículo no disponible. Vehículo ya ocupado: 409. Más días que max-dias: 400.
PUT/api/alquileres/{id} - Modifica un alquiler activo. Si cambia de vehículo, libera el anterior y ocupa el nuevo. Alquiler ya devuelto o nuevo vehículo ocupado: 409.
PUT/api/alquileres/{id}/devolver - OPERACIÓN ESPECÍFICA. Pone activo=false y el vehículo vuelve a disponible. Repetir: 409.
DELETE/api/alquileres/{id} - Solo puede eliminarse si ya fue devuelto. Activo: 409.

6. Estados HTTP utilizados

CódigoUso
200GET/PUT correctos.
201POST correcto, con Location.
204DELETE correcto.
400Datos o parámetros inválidos.
404Recurso concreto no encontrado.
409Conflicto con el estado actual: matrícula/DNI repetido, vehículo ocupado, devolución repetida, relaciones al borrar...

7. Pruebas rápidas con curl.exe

curl.exe http://localhost:8080/api/vehiculos
curl.exe http://localhost:8080/api/vehiculos/disponibles
curl.exe "http://localhost:8080/api/vehiculos?precioMin=30&precioMax=80&disponible=true"
curl.exe http://localhost:8080/api/alquileres/activos
curl.exe http://localhost:8080/api/alquiler/info
En IntelliJ: busca EJEMPLO EXAMEN - para saltar directamente a los patrones más reutilizables.
