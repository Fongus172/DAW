Tienda Decroly Examen

Guía local para consultar endpoints sin Internet. Usa Ctrl+F para buscar palabras como stock, 409, rango, código, pedido o DTO.

Base: http://localhost:8080. Esta página no necesita que Spring Boot esté arrancado para consultarla.

Endpoints

MétodoRutaQué demuestra
GET/api/tienda/infoLee nombre, IVA y máximo de unidades desde application.properties.
GET/api/categoriasLista todas las categorías.
GET/api/categorias/{id}Obtiene una categoría por ID. 404 si no existe.
POST/api/categoriasCrea una categoría. 201 + Location. 409 si el nombre ya existe.
PUT/api/categorias/{id}Modifica una categoría.
DELETE/api/categorias/{id}Borra solo si no tiene productos. 409 si está en uso.
GET/api/categorias/{id}/productosLista los productos de una categoría.
GET/api/categorias/{id}/resumenDTO calculado: productos, stock total y valor del stock.
GET/api/productosLista productos. Acepta filtros opcionales.
GET/api/productos?nombre=tecladoFiltro de texto por nombre.
GET/api/productos?precioMin=20&precioMax=100Filtro por rango de precio.
GET/api/productos?categoriaId=1&limite=5Filtro por categoría + límite con defaultValue.
GET/api/productos/disponiblesProductos con stock > 0.
GET/api/productos/codigo/{codigo}Busca por código único.
GET/api/productos/{id}Obtiene un producto por ID.
POST/api/productosCrea un producto. Valida código único, precio, stock y categoría.
PUT/api/productos/{id}Modifica un producto.
DELETE/api/productos/{id}Borra solo si no tiene pedidos. 409 si está en uso.
GET/api/pedidosLista todos los pedidos.
GET/api/pedidos/{id}Obtiene un pedido por ID.
POST/api/pedidosCrea pedido, comprueba stock, lo descuenta y calcula el total.
PUT/api/pedidos/{id}Modifica pedido y reajusta stock.
DELETE/api/pedidos/{id}Elimina pedido y devuelve unidades al stock.
GET/api/productos/{id}/pedidosLista pedidos de un producto.

Cuerpos JSON útiles

Crear categoría

{
  "nombre": "Informática",
  "descripcion": "Productos de informática y accesorios"
}

Crear producto

{
  "codigo": "TEC-001",
  "nombre": "Teclado mecánico",
  "precio": 49.9,
  "stock": 15,
  "categoriaId": 1
}

Crear pedido

{
  "productoId": 1,
  "unidades": 2
}

Pruebas con curl.exe

curl.exe -i http://localhost:8080/api/productos
curl.exe -i "http://localhost:8080/api/productos?precioMin=20&precioMax=100"
curl.exe -i http://localhost:8080/api/productos/codigo/TEC-001
curl.exe -i http://localhost:8080/api/categorias/1/resumen

Para POST/PUT/DELETE puedes consultar también la colección Postman incluida en la carpeta postman.
