# FestivalSeriesAngular

Proyecto modelo completo para preparar un examen de Angular.

Incluye componentes standalone, interfaces, Data Binding, Control Flow, Input/Output, EventEmitter, Template Forms, Reactive Forms, validaciones, servicios, inyección de dependencias, CRUD local, fetch y Bootstrap.

## Iniciar

```bat
npm install
ng s -o
```

Consulta `README_EXAMEN.md` para la explicación detallada y el mapa de conceptos.
