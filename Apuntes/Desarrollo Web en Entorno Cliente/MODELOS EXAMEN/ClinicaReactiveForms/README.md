# ClinicaReactiveForms

Proyecto modelo de examen para practicar **Reactive Forms en Angular**.

Incluye:

- `ReactiveFormsModule`
- `FormGroup`
- `FormControl`
- `Validators`
- validaciones `required`, `minLength`, `min`, `max` y `pattern`
- validador personalizado de DNI
- validador personalizado de coincidencia de contraseñas
- estados `valid`, `invalid`, `pristine`, `dirty`, `touched` y `untouched`
- `checkControl()` para mostrar errores
- `[disabled]` según la validez del formulario
- alta de pacientes
- edición mediante `setValue()`
- borrado
- `reset()`
- `@if`, `@for` y `@empty`

Consulta también `README_EXAMEN.md`.
