# GestionAlumnosCRUD

Proyecto modelo para el examen de DWEC centrado en CRUD sobre arrays de objetos con Angular.

Conceptos principales: interfaces, arrays, `ngModel`, `@if`, `@for`, `@empty`, `push`, `find`, `findIndex`, `filter`, `splice`, `map`, `forEach`, validaciones y edición de registros.

Consulta `README_EXAMEN.md` para ver la guía comentada y los patrones reutilizables.
