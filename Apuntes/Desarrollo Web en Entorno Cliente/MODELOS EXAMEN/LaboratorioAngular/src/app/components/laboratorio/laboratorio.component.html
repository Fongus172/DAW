2. ngClass y ngStyle

4. Switch

@switch (permiso) { @case ("admin") {
Puedes crear, editar y eliminar contenido.
} @case ("editor") {
Puedes crear y editar contenido.
} @default {
Solo puedes consultar contenido.
} }

5. Directiva personalizada

6. Input Signals

7. Ciclo de vida del componente

El ejemplo permite provocar cambios y destruir/crear el componente. Mira la consola del navegador para observar los hooks.

@if (mostrarCicloVida) { } @else {
El componente está destruido. Al volver a crearlo comenzará un nuevo ciclo de vida.
}
Prioridad de estudio: control flow, bindings y formularios son mucho más importantes. Este laboratorio existe para tener localizadas las partes menos habituales del temario.
