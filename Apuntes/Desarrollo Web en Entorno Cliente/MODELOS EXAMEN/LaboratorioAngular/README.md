# LaboratorioAngular

Proyecto modelo para el examen de DWEC.

Está centrado en conceptos menos frecuentes del temario de Angular:

- Signals.
- Input Signals.
- ngClass.
- ngStyle.
- Event Binding y `$event`.
- Property Binding con innerHTML.
- switch.
- Directiva personalizada con ElementRef.
- Ciclo de vida de componentes.

El proyecto se ha mantenido deliberadamente sencillo y cercano a los ejemplos del profesor.
Consulta `README_EXAMEN.md` para una explicación paso a paso.
